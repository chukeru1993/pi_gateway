# pi RPC → HTTP API 封装方案（修订版）

## 架构总览

```
┌──────────┐   HTTP/SSE (fetch+RS)  ┌───────────────────┐   JSONL/stdin/stdout   ┌──────────┐
│  前端/   │ ←────────────────────→ │   HTTP Gateway     │ ←───────────────────→ │  pi RPC  │
│  调用方  │                        │   (Fastify + TS)   │                       │  子进程   │
└──────────┘                        │                    │                       └──────────┘
                                    │  - 会话池管理       │
                                    │  - 请求路由         │
                                    │  - SSE 事件转发     │
                                    │  - UI 请求桥接      │
                                    │  - 内存/并发控制     │
                                    └───────────────────┘
```

核心思路不变：HTTP Gateway 作为 pi RPC 子进程的代理，将 JSONL 协议映射为 RESTful API + SSE 流，**零侵入 pi 源码**。

## 改进点对照

本修订版针对审查发现的 7 项问题做了以下改进：

| # | 问题 | 改进 |
|---|------|------|
| 1 | `extension_ui_request` 路由未区分对话/即发即弃 | SSE handler 按 method 拆分为 `user_question`(对话) / `notification`(即发即弃) |
| 2 | 缺少 UI 请求超时后的状态同步 | 新增 `GET /sessions/:id/pending-ui-requests` |
| 3 | SSE via POST 的非标准性未强调 | 文档显式标注 + 提供标准 fetch+RS 前端代码 |
| 4 | 会话池无资源监控 | 新增内存监控、自动驱逐、请求级复用选项 |
| 5 | 缺少部分 RPC 命令映射 | 补充 `PUT /config`、`POST /cycle-*`、`PUT /name` 等端点 |
| 6 | 事件转换丢失关键字段 | 透传 `contentIndex`、`partial`、`toolcall_start/delta` |
| 7 | PiProcess 缺少 stdin 背压处理 | 增加 `drain` 事件队列写入 |

## 1. 进程管理：会话池

每个用户/业务会话对应一个 pi RPC 子进程。

```typescript
class PiProcessPool {
  private processes = new Map<string, PiProcess>();
  private maxTotal = 50;
  private maxMemoryPerProcess = 2 * 1024 * 1024 * 1024; // 2GB

  async create(sessionId: string, options: CreateOptions): Promise<PiProcess> {
    if (this.processes.size >= this.maxTotal) {
      throw new Error("Maximum concurrent sessions reached");
    }
    const args = ["--mode", "rpc"];
    if (options.provider) args.push("--provider", options.provider);
    if (options.model) args.push("--model", options.model);
    if (options.noSession) args.push("--no-session");
    if (options.sessionDir) args.push("--session-dir", options.sessionDir);
    if (options.cwd) args.push("--cwd", options.cwd);

    const proc = spawn("pi", args, {
      cwd: options.cwd,
      stdio: ["pipe", "pipe", "pipe"],
    });
    const pi = new PiProcess(sessionId, proc);
    this.processes.set(sessionId, pi);

    pi.startIdleTimer(30 * 60_000);
    pi.startMemoryMonitor(this.maxMemoryPerProcess);
    return pi;
  }

  get(sessionId: string): PiProcess | undefined {
    return this.processes.get(sessionId);
  }

  async destroy(sessionId: string): Promise<void> {
    const pi = this.processes.get(sessionId);
    if (pi) {
      this.processes.delete(sessionId);
      await pi.shutdown();
    }
  }
}
```

## 2. PiProcess 封装（含 stdin 背压处理）

```typescript
class PiProcess {
  private proc: ChildProcess;
  private requestId = 0;
  private pendingResponses = new Map<string, {
    resolve: (msg: any) => void;
    reject: (err: Error) => void;
    timer: NodeJS.Timeout;
  }>();
  private eventListeners = new Set<(event: any) => void>();
  private writeQueue: string[] = [];
  private draining = false;
  private idleTimer?: NodeJS.Timeout;
  private memoryTimer?: NodeJS.Timeout;
  private hangTimer?: NodeJS.Timeout;
  private readonly HANG_TIMEOUT = 5 * 60_000; // 5 分钟
  public intentionalShutdown = false;

  // ─── 会话状态追踪（从 RPC 事件流中提取，供 metrics / admin panel 消费） ───
  public cwd?: string;
  public currentModel?: string;
  public currentProvider?: string;
  public thinkingLevel?: string;
  public isStreaming = false;
  public isCompacting = false;
  public messageCount = 0;
  public pendingMessageCount = 0;
  public steeringQueue: string[] = [];
  public followUpQueue: string[] = [];
  public autoCompactionEnabled = true;
  public autoRetryEnabled = true;
  public createdAt = Date.now();
  public lastActivityAt = Date.now();

  // ─── SSE 连接追踪 ───
  public activeSSEs: Set<object> = new Set();

  // ─── 待处理 UI 对话请求（由 chat handler 写入，PiProcess 统一管理生命周期） ───
  public pendingUiRequests = new Map<string, PendingUIQuestion>();

  constructor(
    public sessionId: string,
    proc: ChildProcess,
    options: { cwd?: string } = {},
  ) {
    this.proc = proc;
    this.cwd = options.cwd;
    this.attachReader();
    proc.stderr?.on("data", (chunk) => {
      // 收集 stderr 用于调试
    });
  }

  private attachReader() {
    let buffer = "";
    this.proc.stdout!.on("data", (chunk: Buffer) => {
      buffer += chunk.toString("utf8");
      while (true) {
        const idx = buffer.indexOf("\n");
        if (idx === -1) break;
        const line = buffer.slice(0, idx);
        buffer = buffer.slice(idx + 1);
        if (line.endsWith("\r")) line = line.slice(0, -1);
        if (line.length > 0) this.handleLine(JSON.parse(line));
      }
    });
  }

  private resetHangTimer() {
    if (this.hangTimer) clearTimeout(this.hangTimer);
    this.hangTimer = setTimeout(() => {
      for (const listener of this.eventListeners) {
        listener({
          type: "error",
          message: "Agent process appears hung (no output for 5 minutes)",
        });
      }
      this.proc.kill("SIGKILL");
    }, this.HANG_TIMEOUT);
  }

  private handleLine(msg: any) {
    this.lastActivityAt = Date.now();
    this.resetHangTimer();

    if (msg.type === "response" && msg.id) {
      const pending = this.pendingResponses.get(msg.id);
      if (pending) {
        clearTimeout(pending.timer);
        this.pendingResponses.delete(msg.id);
        if (msg.success) {
          // 更新状态字段
          if (msg.command === "get_state") {
            const s = msg.data;
            if (s.model) { this.currentModel = s.model.id; this.currentProvider = s.model.provider; }
            if (s.thinkingLevel !== undefined) this.thinkingLevel = s.thinkingLevel;
            if (s.messageCount !== undefined) this.messageCount = s.messageCount;
            if (s.pendingMessageCount !== undefined) this.pendingMessageCount = s.pendingMessageCount;
          }
          if (msg.command === "set_model") {
            if (msg.data?.id) this.currentModel = msg.data.id;
          }
          pending.resolve(msg);
        } else {
          pending.reject(new Error(msg.error));
        }
      }
      return;
    }

    // ─── 从事件流更新状态字段 ───
    switch (msg.type) {
      case "agent_start":
        this.isStreaming = true;
        break;
      case "agent_end":
        this.isStreaming = false;
        break;
      case "compaction_start":
        this.isCompacting = true;
        break;
      case "compaction_end":
        this.isCompacting = false;
        break;
      case "queue_update":
        if (msg.steering) this.steeringQueue = msg.steering;
        if (msg.followUp) this.followUpQueue = msg.followUp;
        break;
    }

    // 所有非响应消息（事件 + extension_ui_request）广播给监听者
    for (const listener of this.eventListeners) {
      listener(msg);
    }
  }

  async sendCommand(cmd: any, timeout = 30_000): Promise<any> {
    const id = `req_${++this.requestId}`;
    return new Promise((resolve, reject) => {
      const timer = setTimeout(() => {
        this.pendingResponses.delete(id);
        reject(new Error(`Command timeout: ${cmd.type}`));
      }, timeout);
      this.pendingResponses.set(id, { resolve, reject, timer });
      this.write({ ...cmd, id });
    });
  }

  sendUiResponse(id: string, response: any) {
    this.write({ type: "extension_ui_response", id, ...response });
  }

  /** 背压安全的写入方法 */
  private write(obj: unknown) {
    const line = JSON.stringify(obj) + "\n";
    if (this.draining) {
      this.writeQueue.push(line);
    } else {
      const ok = this.proc.stdin!.write(line);
      if (!ok) {
        this.draining = true;
        const drainHandler = () => {
          this.proc.stdin!.removeListener("drain", drainHandler);
          this.draining = false;
          for (const queued of this.writeQueue) {
            this.proc.stdin!.write(queued);
          }
          this.writeQueue = [];
        };
        this.proc.stdin!.on("drain", drainHandler);
      }
    }
  }

  onEvent(listener: (event: any) => void): () => void {
    this.eventListeners.add(listener);
    return () => this.eventListeners.delete(listener);
  }

  startIdleTimer(timeoutMs: number) {
    this.idleTimer = setTimeout(() => {
      pool.destroy(this.sessionId);
    }, timeoutMs);
  }

  resetIdleTimer() {
    if (this.idleTimer) {
      clearTimeout(this.idleTimer);
      this.idleTimer.refresh();
    }
  }

  startMemoryMonitor(maxBytes: number) {
    this.memoryTimer = setInterval(async () => {
      try {
        const mem = await this.getChildProcessMemory();
        if (mem > maxBytes) {
          for (const listener of this.eventListeners) {
            listener({
              type: "error",
              message: `Session memory limit exceeded (${Math.round(mem / 1024 / 1024)}MB), shutting down`,
            });
          }
          pool.destroy(this.sessionId);
        }
      } catch {}
    }, 10_000);
  }

  /** 获取子进程 RSS 内存（字节） */
  async getChildProcessMemory(): Promise<number> {
    if (!this.proc.pid) return 0;
    try {
      // Linux: /proc/[pid]/statm 第二列为 RSS（页数 × 4KB）
      const statm = await fs.readFile(`/proc/${this.proc.pid}/statm`, "utf8");
      const pages = parseInt(statm.split(" ")[1], 10);
      if (!isNaN(pages)) return pages * 4096;
    } catch {}
    try {
      // macOS: ps -o rss= -p [pid] 输出 RSS（KB）
      const { execSync } = await import("child_process");
      const out = execSync(`ps -o rss= -p ${this.proc.pid}`, { encoding: "utf8" });
      const kb = parseInt(out.trim(), 10);
      if (!isNaN(kb)) return kb * 1024;
    } catch {}
    return 0;
  }

  /** 查询当前所有待处理的 UI 对话请求 */
  getPendingUiRequests(): PendingUIQuestion[] {
    return Array.from(this.pendingUiRequests.values());
  }

  /** 注册待处理 UI 对话请求 */
  registerPendingQuestion(q: PendingUIQuestion) {
    this.pendingUiRequests.set(q.id, q);
  }

  /** 移除已应答的 UI 对话请求 */
  removePendingQuestion(id: string) {
    this.pendingUiRequests.delete(id);
  }

  /** 标记为主动关闭（避免 exit 事件错误通知） */
  setIntentionalShutdown() {
    this.intentionalShutdown = true;
  }

  async shutdown() {
    this.intentionalShutdown = true;
    if (this.idleTimer) clearTimeout(this.idleTimer);
    if (this.memoryTimer) clearInterval(this.memoryTimer);
    if (this.hangTimer) clearTimeout(this.hangTimer);
    this.proc.kill("SIGTERM");
    setTimeout(() => {
      if (!this.proc.killed) this.proc.kill("SIGKILL");
    }, 1000);
  }
}
```

### 3.2 对话（核心）

**重要：SSE 流端点使用 HTTP POST 返回 `text/event-stream`。标准 `EventSource` 构造函数不支持 POST，前端必须使用 `fetch` + `ReadableStream` 手动解析 SSE 帧。见第 7 节前端示例。**

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/sessions/:id/chat` | 发送消息（返回 SSE 流） |
| POST | `/sessions/:id/steer` | 中途追加指令 |
| POST | `/sessions/:id/follow-up` | 追加后续消息 |
| POST | `/sessions/:id/abort` | 中断当前执行 |

#### 实现

```typescript
interface PendingUIQuestion {
  id: string;
  method: "select" | "confirm" | "input" | "editor";
  title: string;
  message?: string;
  options?: string[];
  placeholder?: string;
  prefill?: string;
  timeout?: number;
}

app.post("/sessions/:id/chat", async (req, reply) => {
  const { id } = req.params;
  const { message, images, streamingBehavior } = req.body;
  const pi = pool.get(id);
  if (!pi) return reply.code(404).send({ error: "Session not found" });
  if (pi.activeSSEs.size > 0) {
    return reply.code(409).send({ error: "Session already has an active chat connection" });
  }

  reply.raw.writeHead(200, {
    "Content-Type": "text/event-stream",
    "Cache-Control": "no-cache",
    Connection: "keep-alive",
    "X-Accel-Buffering": "no",
  });

  const sse = createSSEWriter(reply.raw);
  pi.activeSSEs.add(sse);

  const unsubscribe = pi.onEvent((event) => {
    pi.resetIdleTimer();

    if (event.type === "extension_ui_request") {
      switch (event.method) {
        // ---- 对话方法：需要前端应答 ----
        case "select":
        case "confirm":
        case "input":
        case "editor": {
          const question: PendingUIQuestion = {
            id: event.id,
            method: event.method,
            title: event.title,
            message: event.message,
            options: event.options,
            placeholder: event.placeholder,
            prefill: event.prefill,
            timeout: event.timeout,
          };
          pi.registerPendingQuestion(question);
          sse.write("user_question", question);
          return;
        }
        // ---- 即发即弃方法：不需要应答 ----
        case "notify":
          sse.write("notification", {
            id: event.id,
            message: event.message,
            notifyType: event.notifyType || "info",
          });
          return;
        case "setStatus":
          sse.write("status_update", {
            id: event.id,
            statusKey: event.statusKey,
            statusText: event.statusText,
          });
          return;
        case "setWidget":
          sse.write("widget_update", {
            id: event.id,
            widgetKey: event.widgetKey,
            widgetLines: event.widgetLines,
            widgetPlacement: event.widgetPlacement,
          });
          return;
        case "setTitle":
          sse.write("title_update", {
            id: event.id,
            title: event.title,
          });
          return;
        case "set_editor_text":
          sse.write("editor_text_update", {
            id: event.id,
            text: event.text,
          });
          return;
        default:
          return;
      }
    }

    // 标准 AgentEvent → 透传原始格式，不做转换
    sse.write(event.type, event);
  });

  // 连接断开时清理
  req.raw.on("close", () => {
    unsubscribe();
    pi.activeSSEs.delete(sse);
    pi.resetIdleTimer();
  });

  try {
    await pi.sendCommand({
      type: "prompt",
      message,
      images,
      streamingBehavior,
    });
  } catch (err: any) {
    sse.write("error", { message: err.message });
    sse.end();
  }
});
```

实现：

```typescript
app.post("/sessions/:id/ui-response", async (req, reply) => {
  const { id } = req.params;
  const pi = pool.get(id);
  if (!pi) return reply.code(404).send({ error: "Session not found" });

  const { id: requestId, confirmed, value, cancelled } = req.body;

  if (cancelled) {
    pi.sendUiResponse(requestId, { cancelled: true });
  } else if (confirmed !== undefined) {
    pi.sendUiResponse(requestId, { confirmed });
  } else if (value !== undefined) {
    pi.sendUiResponse(requestId, { value });
  } else {
    return reply.code(400).send({ error: "Must provide confirmed, value, or cancelled" });
  }

});
```

### 6.2 资源管理

```typescript

const IDLE_TIMEOUT = 30 * 60_000; // 30 分钟

// 全局最大进程数
const MAX_TOTAL_PROCESSES = 50;

// SSE 心跳（防止代理/负载均衡器超时）
const heartbeatInterval = setInterval(() => {
  for (const sse of activeSSEConnections) {
    sse.write(": heartbeat\n\n");
  }
}, 15_000);

process.on("beforeExit", () => clearInterval(heartbeatInterval));

// 内存限制：当单进程内存超过 2GB 或总内存超过 80% 系统内存时触发驱逐
class MemoryGuard {
  private maxPerProcess = 2 * 1024 * 1024 * 1024;
  private maxTotalRatio = 0.8;

  async check(pi: PiProcess): Promise<boolean> {
    // 检查系统总内存使用率
    const totalMem = os.totalmem();
    const usedMem = totalMem - os.freemem();
    if (usedMem / totalMem > this.maxTotalRatio) {
      return false;
    }
    // 检查子进程内存（不是 gateway 自身内存）
    const childMem = await pi.getChildProcessMemory();
    if (childMem > this.maxPerProcess) {
      return false;
    }
    return true;
  }

  /** 汇总所有子进程的 RSS 内存（供 admin panel 使用） */
  async getTotalChildMemory(pool: PiProcessPool): Promise<number> {
    let total = 0;
    for (const [, pi] of pool.all()) {
      total += await pi.getChildProcessMemory();
    }
    return total;
  }
}
```

### 6.10 优雅关闭

Gateway 收到 SIGTERM/SIGINT 时，停止接受新请求，关闭所有 SSE 连接和子进程，超时后强制退出。

```typescript
let shuttingDown = false;

// 在 preHandler 中拦截关闭期间的请求
app.addHook("preHandler", async (req, reply) => {
  if (shuttingDown) {
    reply.code(503).send({ error: "Server is shutting down" });
  }
});

async function gracefulShutdown(signal: string) {
  if (shuttingDown) return;
  shuttingDown = true;
  app.log.info(`Received ${signal}, starting graceful shutdown...`);

  // 1. 关闭所有活跃 SSE 连接
  for (const [, pi] of pool.all()) {
    pi.setIntentionalShutdown();
    for (const sse of pi.activeSSEs) {
      (sse as any).end();
    }
  }

  // 2. 销毁所有子进程（带超时）
  const shutdownTimeout = 10_000;
  const destroyPromises = Array.from(pool.all()).map(([, pi]) => pi.shutdown());
  const result = await Promise.race([
    Promise.allSettled(destroyPromises),
    new Promise((r) => setTimeout(() => r("timeout"), shutdownTimeout)),
  ]);
  if (result === "timeout") {
    app.log.warn("Some child processes did not exit within timeout, force killing");
  }

  // 3. 关闭 HTTP 服务器
  await app.close();
  process.exit(0);
}

process.on("SIGTERM", () => gracefulShutdown("SIGTERM"));
process.on("SIGINT", () => gracefulShutdown("SIGINT"));
```

### 6.11 PiProcess 无响应检测（Hang Detection）

当 pi 子进程超过一定时间无任何 stdout 输出时，判定为 hang 并自动销毁。

```typescript
// 在 PiProcess 构造时启动

private readonly HANG_TIMEOUT = 5 * 60_000; // 5 分钟无响应判定 hang

// 在 attachReader 中每次收到行时 reset
private resetHangTimer() {
  if (this.hangTimer) clearTimeout(this.hangTimer);
  this.hangTimer = setTimeout(() => {
    for (const listener of this.eventListeners) {
      listener({
        type: "error",
        message: "Agent process appears hung (no output for 5 minutes)",
      });
    }
    this.proc.kill("SIGKILL"); // 不优雅关闭，直接强杀
  }, this.HANG_TIMEOUT);
}
```

### 7.1 概述

## 8. 前端对接（fetch + ReadableStream 解析 SSE）

```typescript
// SSE 流解析器
async function* parseSSEStream(
  reader: ReadableStreamDefaultReader<Uint8Array>
): AsyncGenerator<{ event: string; data: string }> {
  const decoder = new TextDecoder();
  let buffer = "";
  let currentEvent = "";
  let currentData = "";

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    buffer += decoder.decode(value, { stream: true });

    const lines = buffer.split("\n");
    buffer = lines.pop() || "";

    for (const line of lines) {
      if (line.startsWith("event: ")) {
        currentEvent = line.slice(7);
      } else if (line.startsWith("data: ")) {
        currentData = line.slice(6);
      } else if (line === "" && currentData) {
        // 空行 = 事件结束
        yield { event: currentEvent, data: currentData };
        currentEvent = "";
        currentData = "";
      }
      // 忽略以 ":" 开头的行（注释/心跳）
    }
  }
}

// 使用示例
async function chat(sessionId: string, message: string) {
  const response = await fetch(`/sessions/${sessionId}/chat`, {
    method: "POST",
    headers: { "Content-Type": "application/json", Authorization: `Bearer ${token}` },
    body: JSON.stringify({ message }),
  });
  if (!response.ok) throw new Error(`HTTP ${response.status}`);

  const reader = response.body!.getReader();

  for await (const { event, data } of parseSSEStream(reader)) {
    const payload = JSON.parse(data);

    switch (event) {
      case "message_update": {
        const ame = payload.assistantMessageEvent;
        if (ame.type === "text_delta") {
          appendToUI(ame.delta);
        } else if (ame.type === "thinking_delta") {
          appendThinking(ame.delta);
        } else if (ame.type === "toolcall_end") {
          showToolCall(ame.toolCall);
        }
        break;
      }

      case "tool_execution_start":
        showToolExecution(payload.toolCallId, payload.toolName, payload.args);
        break;

      case "tool_execution_update":
        updateToolExecution(payload.toolCallId, payload.partialResult);
        break;

      case "tool_execution_end":
        finishToolExecution(payload.toolCallId, payload.result, payload.isError);
        break;

      case "user_question":
        // 对话方法：弹出 UI 等待用户应答
        const answer = await showDialog(payload as PendingUIQuestion);
        await fetch(`/sessions/${sessionId}/ui-response`, {
          method: "POST",
          headers: { "Content-Type": "application/json", Authorization: `Bearer ${token}` },
          body: JSON.stringify({
            id: payload.id,
            ...(payload.method === "confirm"
              ? { confirmed: answer }
              : { value: answer }),
          }),
        });
        break;

      case "notification":
        showToast(payload.message, payload.notifyType);
        break;

      case "status_update":
        updateStatusBar(payload.statusKey, payload.statusText);
        break;

      case "widget_update":
        if (payload.widgetLines) {
          renderWidget(payload.widgetKey, payload.widgetLines, payload.widgetPlacement);
        } else {
          removeWidget(payload.widgetKey);
        }
        break;

      case "title_update":
        document.title = payload.title;
        break;

      case "editor_text_update":
        setEditorContent(payload.text);
        break;

      case "error":
        showError(payload.message);
        break;

      case "agent_end":
        return payload.messages;
    }
  }
}
```

## 9. 方案总结

| 维度 | 方案 |
|------|------|
| **底层通信** | pi `--mode rpc` 子进程，JSONL over stdin/stdout |
| **对外协议** | RESTful API + SSE 流（POST 端点返回 `text/event-stream`） |
| **会话模型** | 每用户一个 pi 子进程，空闲超时 + 内存阈值驱逐 |
| **流式输出** | 透传原始 `AgentEvent` 格式，不拆解不丢失字段 |
| **UI 对话方法** | `user_question` SSE 事件 + `POST /ui-response` 端点 |
| **UI 即发即弃方法** | `notification` / `status_update` / `widget_update` / `title_update` / `editor_text_update` SSE 事件，无需应答 |
| **重连恢复** | `GET /pending-ui-requests` 查询待处理 UI 请求 |
| **中途追加** | `POST /steer` 和 `POST /follow-up` |
| **配置** | `PUT /config` 批量设置 steering/followUp 模式、自动压缩/重试 |
| **可视化管理** | 内置 `/admin` 面板（零额外依赖，vanilla HTML+CSS+JS）：全局指标、会话列表/详情、最近事件流、告警提示 |
| **安全** | JWT 认证 + cwd 白名单 + bash 命令过滤 + rate limiting |
| **资源管理** | 最大 50 并发、单进程 2GB 上限、30 分钟空闲回收、SSE 心跳 |
| **部署** | Docker + docker-compose，带健康检查 |
| **前端要求** | 必须使用 `fetch` + `ReadableStream` 解析 SSE（`EventSource` 不支持 POST） |
